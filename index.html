Freelance

Sizin için neler yapabilirim?

İşletmelerle ve küçük ekiplerle çalışıyorum. İşe ne istediğinizi konuşarak başlıyoruz. Gerekmeyen sayfa ve özellikleri baştan eliyoruz, böylece bütçe asıl işe gidiyor.

01

Kurumsal site & landing page

Ne iş yaptığınızı ilk ekranda anlatan, telefonda düzgün görünen ve hızlı açılan siteler.

  • Tasarım
  • Hız
  • Temel SEO
02

Web uygulaması & yönetim paneli

Ekibinizin her gün kullanacağı ekranlar: kullanıcı rolleri, raporlar, size özel iş akışları. ASP.NET Core ile, ileride büyütmesi kolay olacak şekilde.

  • ASP.NET Core
  • SQL Server
  • Yetkilendirme
03

API & entegrasyon

Ödeme, CRM, e-posta, WhatsApp ya da yapay zekâ servislerini mevcut sisteminize bağlıyorum. Servis cevap vermediğinde ne olacağı da işin bir parçası.

  • REST
  • Otomasyon
  • AI API
04

Performans, bakım & iyileştirme

Yavaşlamış ya da eskimiş bir siteniz varsa devralıp toparlıyorum. Sonrasında düzenli bakımla takipte kalıyorum.

  • Core Web Vitals
  • Güvenlik
  • Bakım
